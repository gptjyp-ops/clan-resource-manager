# 클랜 도우미

클랜 입장 후 오른쪽 아래의 **클랜 도우미** 버튼을 누릅니다.

- 등록 현황: 서버에서 최신 기록을 읽고 기존 주간 등록 기준으로 분류합니다.
- 등록 안내문: 같은 현황으로 복사 가능한 초안을 만듭니다. 자동 발송하지 않습니다.
- 사용법: 기본 등록 절차를 안내합니다.
- 자유 질문: 별도 전송 동의 후 질문 내용만 Google Gemini API로 전송합니다. 각 질문은 독립적으로 처리하며 이전 대화는 전송하지 않습니다.

위 세 버튼은 생성형 AI 없이 작동합니다. 기록이 한 번도 없는 회원은 집계할 수 없습니다. 대화는 브라우저 메모리에만 보관되며 최대 30개 메시지를 표시합니다.

## AI 연결

기존 Google Apps Script 프로젝트의 프로젝트 설정 → 스크립트 속성에 다음 값을 설정합니다.

- `GEMINI_API_KEY`: 운영자의 Gemini API 키. 저장소나 브라우저에 입력하지 않습니다.
- `GEMINI_MODEL`: 해당 키에서 사용 가능한 텍스트 생성 모델 ID. Google AI Studio에서 확인합니다.

설정 전에는 자유 질문에 연결 전 안내가 표시됩니다. 코드 반영은 기존 Google 배포 워크플로를 사용합니다. 최초 외부 요청 권한 승인이 필요한 경우 운영자가 Apps Script 권한을 승인해야 합니다.

호출은 클랜 입장 인증 후에만 허용됩니다. 클랜당 10초 간격·UTC 하루 20회, 전체 UTC 하루 200회로 서버에서 제한합니다. 실패 요청도 한도에 포함됩니다. 한도는 금액 예산이 아니므로 제공사 사용량과 청구도 확인합니다.

AI에는 클랜 기록·사진·입장 코드·회원 인증 정보를 자동 전송하지 않습니다. 자유 질문에 직접 입력한 내용은 Google AI로 전송되며 제공사 설정과 약관이 적용됩니다. AI는 공지 문구와 사용법을 돕는 읽기 전용 기능이며 실제 기록 분석·점수 계산 도구는 없습니다.
