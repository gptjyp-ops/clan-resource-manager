1. 클랜 입장 · 등록 준비

이 책자는 사이트에서 등록하는 순서대로 진행합니다. 한 단계씩 따라 하고 마지막에 한 번에 저장하세요.

01
클랜 초대 링크로 입장

클랜장이 보내준 초대 링크를 엽니다. 코드가 채워져 있으면 ‘클랜 현황 열기’를 누르세요.

02
‘내 재화’ 탭 열기

처음 등록한다면 위쪽 ‘내 재화 불러오기’ 로그인은 건너뛰고, 아래 ‘내 재화 등록’의 게임 닉네임을 입력하세요. 이미 등록했다면 위쪽에서 같은 닉네임과 기존 본인 수정 비밀번호로 로그인해 기록을 불러옵니다.

03
저장 방식 선택

처음 네 종류를 등록할 때는 ‘전체 모아서 저장’을 선택하세요. 이미 저장한 일부 재화만 바꿀 때는 ‘일부 항목 저장’을 선택합니다. 같은 사람은 기존 닉네임을 그대로 사용하세요.

04
사진 올리는 방법 확인

휴대폰은 각 사진 칸에서 사진첩·파일을 선택합니다. PC는 해당 사진 칸을 클릭하고 Ctrl+V를 누르거나 ‘복사한 캡처 붙여넣기’를 사용하세요. JPG·PNG·WEBP, 최대 10MB까지 지원합니다. 붙여넣기가 안 되면 PNG로 저장해 파일로 올리세요.

탭을 바꿔도 입력한 내용은 유지됩니다. 사진을 읽은 것만으로 저장되지는 않아요.

4. 알 합성 등록

‘알’ 탭 아래 ‘합성 수량’에 업그레이드 화면 사진을 올립니다.

① 사진 선택 수량

‘167 선택됨’ → 167개입니다. 등급별 31+31+31+68+6도 합계 167개입니다. 화면에 보이는 카드만 세지 않습니다.

추가 수량 (+α)

‘선택됨’에 포함되지 않은 재료만 입력하세요. 펫만 선택되어 알이 빠졌다면 빠진 알을 확인해 더합니다. 예: 167 + 빠진 3개 = 합성 170개. 빠진 재료가 없으면 추가하지 않습니다.

알 소환과 합성 값까지 확인했다면 ‘탈것’ 탭으로 이동하세요.

8. 전체 확인 · 저장

스킬·알·탈것·물약을 모두 확인한 뒤 마지막에 저장합니다.

01
‘한 번에 저장할 내역’의 4/4 확인

네 종류의 보유 수량, 소환 레벨·현재 단계, 알·탈것 합성 수량을 다시 비교하세요. 미입력이나 잘못 읽힌 값은 해당 탭으로 돌아가 사진을 다시 인식합니다. 계속 틀린 항목은 사진을 보며 해당 값만 수기로 고칩니다.

02
본인 수정 비밀번호 입력

처음 등록할 때는 본인 수정 비밀번호를 6자 이상으로 정합니다. 기존 재화 수정이라면 처음 정했던 같은 비밀번호를 사용하세요. 이 비밀번호가 다음 ‘내 재화 불러오기’ 로그인에 필요합니다.

03
‘4종 재화 한 번에 저장’ 누르기

버튼을 누르고 저장 성공 메시지가 나올 때까지 기다립니다. 사진 인식 완료나 4/4 표시만으로 서버 저장이 끝난 것은 아닙니다.

일부만 수정한다면
‘일부 항목 저장’을 선택하고 변경한 값만 입력한 뒤 ‘입력한 재화 저장’을 누릅니다. 빈칸과 수정하지 않은 재화·사진은 기존 기록을 유지합니다. 0을 직접 입력하면 해당 수량을 0으로 수정합니다.
저장 실패 시 화면을 닫지 마세요.
‘저장 연결 다시 확인’을 이용하고 다시 저장하세요. 임시 보관본이 있으면 같은 기기·브라우저에서 불러올 수 있습니다. 현황에서 실제 저장 여부를 확인합니다.
클랜 입장 코드 · 본인 수정 비밀번호 · 클랜장 관리 비밀번호는 서로 다릅니다. 비밀번호를 톡방이나 오류 제보에 넣지 마세요.

9. 저장한 현황 확인

저장 성공 후 ‘클랜 현황’ 탭에서 내 닉네임과 수량이 반영됐는지 확인하세요.

다음에 내 재화를 볼 때
같은 클랜 초대 링크로 들어와 ‘내 재화’ → ‘내 재화 불러오기’에서 등록한 게임 닉네임과 본인 수정 비밀번호를 입력합니다. 새로 등록할 필요 없이 저장한 내역을 불러올 수 있어요.
01
클랜 현황에서 확인·정렬

내 재화와 클랜 현황은 별도 탭입니다. 보유 재화 요약에서 스킬·알·탈것·녹색 물약·알 합성·탈것 합성 총 6개의 합계를 함께 볼 수 있어요. 내 재화는 본인 수량, 클랜 현황은 클랜 전체 합계입니다. 알 합성·탈것 합성도 각각 정렬할 수 있어요. 버튼 한 번은 내림차순, 다시 누르면 오름차순입니다. 합성은 선택 수량 + 추가 수량 기준, 미입력은 마지막입니다.

02
다시 인식해도 다르면

‘이 사진 다시 인식’을 사용하고, 인식 연습에서는 일반 인식이 실패하면 호환 인식으로 시도하세요. 오류가 없어도 원본과 숫자가 일치하는지 확인해야 합니다.

03
오류 전달

원본 게임 캡처, 재화 종류, 올바른 값, 실제 읽힌 값, ‘오류 정보 복사’ 내용을 함께 보내주세요. 예: 물약 / 원본 1.14k / 결과 114. 클랜 입장 코드와 비밀번호는 제외합니다.

04
클랜장: 새 클랜 만들기

클랜장 관리에서 새 클랜 이름·서버 번호·클랜장 비밀번호(10자 이상)를 설정합니다. 생성한 관리 정보를 보관하고 클랜원에게 초대 링크를 공유하세요. 기존 기록은 ‘기존 클랜 연결’을 사용하며 새 클랜에 자동 이전되지 않습니다.
