## 보존 원칙

임시 보관은 해당 기기·브라우저에만 남으며 서버 등록과 구분한다. 비밀번호·초대 코드·로그인 토큰을 보관하지 않는다. 브라우저 데이터 삭제·비공개 모드·저장 공간 부족으로 복구가 안 될 수 있음을 안내한다. 사용자의 명시적 저장 없이 자동 재전송하지 않는다. 저장이 서버에서 성공하면 해당 임시본만 정리한다.
