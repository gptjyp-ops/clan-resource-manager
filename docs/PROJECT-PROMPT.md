# 프로젝트 작업 지침

## 2026-10-04 추가

개선 요청을 하나씩 배포하지 않고 목록으로 모아 묶음 수정·테스트·배포한다. 단, 기존 데이터 삭제·권한 노출 등 긴급 오류는 우선 해결한다. 진행 상황과 미완료 항목은 RELEASE-PLAN.md에 유지한다.

기존 등록을 수정할 때 변경한 필드만 갱신한다. 빈칸·미인식·기본 추가 수량 0 때문에 기존 기록이 지워져서는 안 된다. 사용자가 명시적으로 입력한 0은 유효한 수정값이다.

100레벨 승천대기 상태에는 ‘승천 추천 재화량: 60k(60,000개) 이상’을 안내한다.

업데이트 또는 연결 장애 중에도 입력·사진 인식을 계속할 수 있고 기기에 임시 보관한다. 임시 보관과 서버 등록 완료를 구분하고 비밀번호·초대 코드·토큰을 저장하지 않는다. 연결 회복 후 사용자가 비밀번호를 입력하고 직접 저장한다. 자동 재전송은 하지 않는다.

저장 프로토콜 변경 시 구글 저장 서버를 먼저 배포·확인하고 사이트를 나중에 배포한다. 기존 데이터를 손상시킬 수 있는 구버전에는 저장하지 않는다. 코드 검사·테스트·배포 성공과 실제 운영 저장 확인을 구분해 설명한다.
