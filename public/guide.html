사진으로 배우는 재화 등록

네가 올린 실제 게임 캡처 6장으로, 읽어야 할 위치부터 차근차근 확인해요.

01
클랜 초대 링크 열기

클랜장이 보내준 링크로 입장하세요. 코드가 채워져 있으면 ‘클랜 현황 열기’를 누릅니다. 클랜장 관리 비밀번호와 본인 수정 비밀번호는 서로 달라요.

02
사진 4종 + 합성 사진 2장 준비

스킬·알 소환·탈것 소환·녹색 물약이 기본 4종입니다. 알 합성과 탈것 합성은 ‘선택됨’ 숫자가 보이는 별도의 화면을 준비합니다.

03
저장 없이 먼저 연습

사진 인식 연습에서 파일을 올려보세요. 연습 결과는 클랜 기록에 저장되지 않습니다.

04
사진과 결과 비교 후 저장

수량·소수점·k·소환 레벨·0단계까지 비교하세요. 아래 예시는 설명용 과거 수량이며, 자신의 현재 사진 값을 등록해야 합니다.

  • 스킬·알 소환
  • 탈것 소환
  • 알·탈것 합성
  • 녹색 물약
  • 업로드·로그인·저장
  • 클랜 현황·오류·클랜장
사진 위 주황색 테두리와 번호는 안내용입니다. 실제로 등록할 때는 표시를 덧그리지 않은 원본 게임 캡처를 올려주세요.

보유 소환 재화가 아니라, 업그레이드 화면의 ‘선택됨’ 숫자를 읽어요.

사진 업로드부터 전체 저장까지

사진을 읽은 것만으로 저장이 완료되지는 않아요.

01
내 재화 탭에서 닉네임 입력

처음 등록하는 게임 닉네임을 정확히 입력합니다. 이미 등록했다면 ‘내 재화 불러오기’에서 같은 닉네임과 기존 본인 수정 비밀번호로 로그인하세요.

02
각 재화의 사진 칸에 업로드

휴대폰은 사진첩 또는 파일 선택, PC는 해당 사진 칸을 선택한 뒤 Ctrl+V 또는 ‘복사한 캡처 붙여넣기’를 사용합니다. JPG·PNG·WEBP, 최대 10MB까지 지원합니다. 붙여넣기가 안 되면 PNG로 저장해 파일로 올려보세요.

03
스킬 → 알 → 탈것 → 물약 확인

탭을 바꿔도 읽은 값은 유지됩니다. 알·탈것의 합성 사진은 각 탭의 합성 수량 영역에 따로 올립니다. 인식이 끝난 뒤 사진과 결과를 대조하세요. 사진 미리보기를 눌러 확대할 수 있습니다.

04
4/4 완료 후 저장

‘전체 모아서 저장’에서 네 종류를 모두 확인하세요. 처음 정한 본인 수정 비밀번호(6자 이상)를 입력하고 ‘4종 재화 한 번에 저장’을 누릅니다. 성공 메시지와 클랜 현황을 확인하세요.

05
일부 항목만 수정할 때

‘일부 항목 저장’으로 바꾸고 필요한 값만 수정합니다. 빈칸은 기존 저장값을 삭제하지 않습니다. 0을 직접 입력하면 해당 수량을 0으로 수정합니다. 새 닉네임으로 저장하면 별도 기록이 되니 기존 닉네임을 그대로 사용하세요.

비밀번호를 구분하세요. 클랜 입장 코드 → 클랜 열기 / 본인 수정 비밀번호 → 내 재화 로그인·수정 / 클랜장 비밀번호 → 클랜 관리. 비밀번호를 톡방이나 오류 제보에 넣지 마세요.
저장 실패가 나오면 재등록 성공을 확인하기 전까지 화면을 닫지 마세요. 임시 보관 안내가 있으면 해당 보관본으로 다시 시도할 수 있습니다.

클랜 현황과 문제 해결

등록 후 확인·정렬하고, 오류가 있다면 정확한 자료를 전달해요.

01
클랜 현황에서 확인·정렬

내 재화와 클랜 현황은 별도 탭입니다. 스킬·알·탈것·녹색 물약뿐 아니라 알 합성·탈것 합성도 정렬할 수 있어요. 버튼 한 번은 내림차순, 다시 누르면 오름차순입니다. 합성은 선택 수량 + 추가 수량 기준, 미입력은 마지막입니다.

02
다시 인식해도 다르면

‘이 사진 다시 인식’을 사용하고, 인식 연습에서는 일반 인식이 실패하면 호환 인식으로 시도하세요. 오류가 없어도 원본과 숫자가 일치하는지 확인해야 합니다.

03
오류 전달

원본 게임 캡처, 재화 종류, 올바른 값, 실제 읽힌 값, ‘오류 정보 복사’ 내용을 함께 보내주세요. 예: 물약 / 원본 1.14k / 결과 114. 클랜 입장 코드와 비밀번호는 제외합니다.

04
클랜장: 새 클랜 만들기

클랜장 관리에서 새 클랜 이름·서버 번호·클랜장 비밀번호(10자 이상)를 설정합니다. 생성한 관리 정보를 보관하고 클랜원에게 초대 링크를 공유하세요. 기존 기록은 ‘기존 클랜 연결’을 사용하며 새 클랜에 자동 이전되지 않습니다.
