개선 요청을 하나씩 배포하지 않고 목록으로 모아 묶음 수정·테스트·배포한다. 단, 기존 데이터 삭제·권한 노출 등 긴급 오류는 우선 해결한다. 진행 상황과 미완료 항목은 RELEASE-PLAN.md에 유지한다.

기존 등록을 수정할 때 변경한 필드만 갱신한다. 빈칸·미인식·기본 추가 수량 0 때문에 기존 기록이 지워져서는 안 된다. 사용자가 명시적으로 입력한 0은 유효한 수정값이다.

100레벨 승천대기 상태에는 ‘승천 추천 재화량: 60k(60,000개) 이상’을 안내한다.

업데이트 또는 연결 장애 중에도 입력·사진 인식을 계속할 수 있고 기기에 임시 보관한다. 임시 보관과 서버 등록 완료를 구분하고 비밀번호·초대 코드·토큰을 저장하지 않는다. 연결 회복 후 사용자가 비밀번호를 입력하고 직접 저장한다. 자동 재전송은 하지 않는다.

저장 프로토콜 변경 시 구글 저장 서버를 먼저 배포·확인하고 사이트를 나중에 배포한다. 기존 데이터를 손상시킬 수 있는 구버전에는 저장하지 않는다. 코드 검사·테스트·배포 성공과 실제 운영 저장 확인을 구분해 설명한다.
# OCR 결과 검증 추가

클랜 초대 입장 화면의 코드 입력칸 옆에 눈 모양 보기/숨기기 버튼을 제공한다. 기본은 가림 상태이며 클릭해도 코드 값이나 입장 요청을 바꾸지 않는다. 눈 버튼은 폼을 제출하지 않아야 한다. 한국어와 영어 접근성 설명을 제공하며 코드를 로그·진단·스크린샷에 노출하지 않는다.

클랜원 재화 현황에서 스킬·알·탈것·녹색 물약별 정렬 버튼을 제공한다. 처음 클릭하면 보유 재화가 많은 순(내림차순), 다시 클릭하면 적은 순(오름차순)으로 전환한다. k 등 축약 표시는 숫자로 환산하여 비교하고 0은 실제 값으로 처리한다. 미입력은 양방향 모두 마지막에 표시한다. 최근 등록순으로 돌아가는 버튼을 제공한다. 정렬은 화면만 변경하고 저장 데이터는 수정하지 않는다. 영어에서도 동일하게 사용할 수 있도록 한다.

숫자가 읽혔다는 이유만으로 성공 처리하지 않는다. 합성 수량은 실제 숫자 자리수와 인식된 자리수를 비교한다. `111`이 `1`로 반환되면 각 자리 숫자를 다시 읽고, 확실히 재확인하지 못하면 OCR-04 오류를 보여준다. 합성 화면이 아닌 사진에서 고정 위치의 다른 숫자를 합성 수량으로 사용하지 않는다.
