Getting started as a clan member

Upload a screenshot, check the numbers, then save your resources.

01 Enter your clan

Open the invitation link from your clan leader. If an access code is required, enter the code they gave you. Do not share admin passwords in group chats.

02 Prepare your screenshots

Capture the skills, egg summon, mount summon and green potion screens. To submit merge counts, also capture the egg and mount merge screens with the selected count visible.

03 Practise without saving

The photo scan practice page reads your screenshot and displays the result without saving clan records. Try Standard scan first. If it fails, try Compatibility scan with the same photo.

Practice checklist

Have you received the correct clan link? Can you identify all four resource screens? Remember that summon screens and merge screens are different photos.

Uploading screenshots

Use a phone photo file or a screenshot copied on your PC.

01 Choose a file

Select the correct resource tab, then select its photo upload area. Choose a screenshot from your phone or PC. JPG, PNG and WEBP files up to 10MB are supported.

02 Paste on your PC

Copy a screenshot, select the correct photo area, and press Ctrl+V. You can also select Paste copied screenshot. Allow clipboard access if your browser asks. If pasting is unavailable, save the capture as a PNG and choose the file instead.

03 Keep the numbers visible

Include the amount, summon level and current stage. Use an original screenshot without marks over the numbers. Cropped or blurry photos can be harder to scan. Wait until the scan finishes before continuing.

Practice checklist

Choose a green potion screenshot in Photo scan practice. Compare the result with the preview. This exercise does not save your clan inventory.

Checking all four resources

Compare the result with the original photo before trusting the totals.

01 Skills, eggs and mounts

Check the currency held, summon level and current stage. The level of an individual skill, pet or mount card is different from the summon level next to the summon button. Lv.32 with 0/23 means summon level 32 and current stage 0. Zero is a valid value, not a blank field.

02 Maximum summon level

When the summon information shows the Korean label “최대” (Max), it means summon level 100 and is displayed as Awaiting ascension. Below level 100, it is Ascension unavailable. This does not mean the equipped card is level 100.

03 Two green potion screens

You can use either the main technology tree or the detailed clan technology screen. Read only the count beside the green vial at the upper left. Red potions, gems and technology percentages are different values.

04 Decimal points and k

3.3k = approximately 3,300 items; 24k = approximately 24,000; 2.73k = approximately 2,730. The game abbreviates these amounts, so totals are approximate. If a 3.3k photo is read as 33k or 33,000, the decimal point was misread. Scan again and send the original to the operator before saving.

Practice questions

Is 3.3k → 33,000 correct? Is 0/23 → current stage 0 correct? Find the answers on the last page.

Merges and saving all resources

Avoid adding the same materials twice.

01 Egg and mount merge photos

Upload the merge screenshot in that resource’s Merge count section. A selected count of 57 means 57, and 388 means 388. The scanner reads the selected number rather than counting the cards visible on screen.

02 Additional count (+α)

Add only merge materials excluded from the selected count in your photo. For example, if only pets were selected and some eggs were excluded, enter the excluded quantity when you know it. Selected 57 + additional 3 = total merge count 60. Never add an already selected item again.

03 Save all four together

Enter your in-game nickname and choose Save all four resources. Upload Skills → Eggs → Mounts → Potions. Values stay when you switch tabs. Check that the review shows 4/4 complete. Choose an edit password of at least 6 characters, then select Save all four resources.

04 Confirm success

Check the success message and your nickname in Member resources. Select your nickname to view details and photos. In Save selected resources mode, blank fields preserve previously saved values. Entering 0 explicitly updates that field to zero.

Practice questions

What is the total if the selected count is 57 and the additional count is 3? Can you save all four resources if you have entered only green potions?

Retrying, editing and reporting errors

Do not save values that disagree with your screenshot.

01 Retry the scan

Select Scan this photo again. On the practice page, try Compatibility scan when Standard scan fails. A displayed number can still be wrong. Compare the decimal point, k suffix, summon level and stage 0 with the original.

02 Edit your saved inventory

Select your nickname in Member resources, then Edit my resources. Upload updated photos, check the results and save with the edit password you originally chose. Your edit password is separate from the clan admin password.

03 Error codes

IMG-01: photo could not be opened. IMG-02: format or size problem. OCR-01: engine could not load. OCR-02: number area not found. OCR-03: number in the area could not be read. OCR-05: scan runtime error. SAVE-01: save error.

04 Send useful evidence

Send the original screenshot, resource tab, expected value, actual result and Copy diagnostics text to the operator. Example: green potion photo 3.3k, result 33,000. Do not send passwords, access codes or gift-card PINs.

Practice questions

Can a number look valid but be ten times too large? Should you compare the photo even if diagnostics says issues: []? Yes to both.

Clan leader guide and answers

Keep admin details separate from member invitations.

01 Create a new clan

Open Clan admin and select Create a clan. Enter the clan name, server number and an admin password of at least 10 characters. Keep the clan ID and admin URL safe. Share only the member invite link with members.

02 Connect an existing clan

If you already have records, select Connect existing clan with the old access code and a new admin password. If the server field is disabled, the service operator must update Google Apps Script. Creating a new clan does not automatically move old records.

03 Change servers or invitations

After signing in as admin, use Save clan server to update the number. Different clans on the same server still have separate records. Changing the invite link disables the previous link and access code, so share the new link with members.

04 Optional support

Select Support this project to view the operator’s details. Support is optional and all features are available to everyone. If the panel says Support options coming soon, no payment or transfer is connected yet.

Practice answers

3.3k → 33,000 is wrong; the correct conversion is approximately 3,300. Stage 0 in 0/23 is valid. 57 + 3 = 60 merges. Entering only potions is not enough to save all four resources.

Your screenshot examples

Actual screenshot examples

Tap a screenshot to view it larger in a new tab. These are past example values; register your own current amounts.

Current save and login behaviour

Partial saves keep existing values when fields are blank. Entering 0 explicitly updates that field to zero.

Merge sorting

Egg merges and Mount merges have separate sort buttons in Clan overview. First click: descending. Click again: ascending. Sorting includes selected + extra counts; missing entries stay last.

Decimals and units

1.14k means approximately 1,140, not 114 or 114,000. OCR-04 means the digit count, decimal or unit could not be confirmed. Compare with the screenshot before saving.
