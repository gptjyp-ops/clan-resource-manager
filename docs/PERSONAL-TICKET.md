# 개인 인증 방식

현재 기본 인증은 수정 비밀번호입니다.

- 신규 회원은 닉네임과 사진·수량을 입력한 뒤 수정 비밀번호(6~100자)를 정해 저장합니다. QR을 자동 발급하지 않습니다.
- 기존 회원은 사진·수량을 변경한 뒤 등록한 수정 비밀번호로 저장합니다. 내 재화 불러오기도 비밀번호를 사용하며 인증 수단을 바꾸지 않습니다.
- 예전에 QR을 발급받은 회원은 기존 QR로 본인 확인한 뒤 새 수정 비밀번호를 입력해 재화를 저장합니다. 서버는 기존 QR을 검증한 다음 저장과 함께 비밀번호를 전환합니다. 성공 시 이 기기의 QR을 지우고 이전 QR을 무효화합니다.
- QR과 비밀번호를 모두 잃은 경우 기존 개인 복구 코드 또는 클랜장·운영자 복구 절차를 사용합니다. 과거 비밀번호는 QR 발급 시 교체되었으므로 복원할 수 없습니다.
- 클랜 입장은 개인 인증과 별개이며 초대 코드·입장 비밀번호를 사용합니다.
- 비밀번호 원문은 서버에 보관하지 않고 개인별 salt와 HMAC 해시로 검증합니다. 공개 현황에 인증 정보를 포함하지 않습니다.

기존 QR 관련 코드와 발급·폐기 기능은 호환성을 위해 유지합니다. 프런트엔드의 일반 회원 등록·로그인에서는 발급하지 않습니다.
