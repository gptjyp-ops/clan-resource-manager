# 2026-10-04 OCR 수정

- 원본 탈것 합성 사진에서 `111 선택됨`이 `1`로 반환되는 문제를 재현했다.
- 합성 수량은 숫자의 분리된 자리수를 확인하고, 결과 자리수가 다르면 한 자리씩 다시 읽는다. 재확인에 실패하면 OCR-04로 표시한다.
- 일반 알 화면처럼 합성 패널이 없는 사진은 합성 수량의 고정 위치를 읽지 않는다. 잘못된 칸의 숫자가 성공으로 저장되는 것을 막는다.
- 원본 사진의 실제 OCR 검사에서 수정 후 `111`을 확인했다. 첫 사진은 일반 알 화면이므로 알 기본 정보 칸에 올려야 한다.
