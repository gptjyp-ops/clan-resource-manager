# 클랜장 전용 회원 복구

1. 클랜장 관리 페이지에서 자기 클랜으로 관리 로그인합니다.
2. 클랜장 전용 회원 복구 → 클랜 전용 복구 코드 발급·재발급을 누릅니다.
3. 발급된 CLAN- 코드를 복사해 클랜장만 보관합니다. 서버에는 원문 대신 salted HMAC 해시를 보관합니다.
4. 이후 관리 로그인 없이도 같은 관리 페이지의 클랜 전용 코드로 회원 비밀번호 재설정에서 클랜 ID, 복구 코드, 회원 닉네임, 새 비밀번호와 확인을 입력합니다.
5. 코드는 해당 클랜 회원에게만 유효하며 여러 회원에게 사용할 수 있습니다. 회원에게 코드 자체를 보내지 말고 클랜장이 직접 재설정합니다.
6. 재발급하면 이전 클랜 코드는 무효화됩니다. 회원을 복구하면 예전 비밀번호·QR·개인 복구 코드는 무효화되며 재화·사진·등록일은 유지됩니다.

정상 회원 비밀번호 로그인은 읽기 전용 경로에서 확인하여 공유 저장 잠금을 기다리지 않습니다. 실패 기록 변경과 실제 복구·저장은 기존 잠금으로 보호합니다. 이 변경은 Apps Script 전체 동시 실행 한도를 제거하는 것은 아닙니다.
